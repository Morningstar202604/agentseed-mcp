# AgentSeed 使用指南（写给使用者）

> 一句话定位：**AgentSeed 是收尾闸门，不是开场咒语。** 它不帮你写代码，
> 也不在任务开头替你把关——它在 AI 宣称"完成"的那一刻强制验证，
> 证据来自真实运行的检查，而不是 AI 的自我报告。
> 你的职责只有两段：**开场把约束说清楚，收尾把证据要到手。**

## 推荐工作流：开场约束 → 中段旁观 → 收尾验票

### 第一段：开场约束提示词（任务开始时粘贴给 AI）

直接复制这段话发给 AI，再交给它任务：

```
本次任务启用 AgentSeed 闸门，请遵守：
1. 动手前先用一句话说明你按什么契约实现；契约不明确就先问我。
2. 调用任何你没见过的 API/函数前，先用 resolve_symbol 确认它存在。
3. 新增依赖前，先用 check_imports 核实包名，防止幻觉包进锁文件。
4. 只写真实实现：不许用 stub/TODO/placeholder 充当可运行逻辑。
5. 宣称完成前必须让 verify_code 和 scan_hallucination 都通过；
   "测试通过"这类结论必须用 sandbox_run 附上退出码和输出作证。
6. 完成报告必须附证据：命令、退出码、改动文件清单，
   并用 record_verification 存证，最后跑一次 gate 给我看结果。
```

这六条分别对应闸门的六根桩：契约先行、API 预查、依赖核实、禁止桩代码、
强制验证、证据存档。**开场说这六条就够了**——堆更多原理和长篇约束只会
稀释重点，AI 的注意力是稀缺资源。

### 第二段：中段你只盯一件事

看到 AI 调用 `agentseed_*` 工具（verify_code、scan_hallucination……）
= 闸门在工作。AI 被拦后自己修复再重跑 = 正常流程。
如果它跳过验证直接说"做完了"，你只需要回一句：
**"先过闸门，再谈完成。"**

### 第三段：收尾验收（这是硬的）

任务结束时，向 AI 索要三样东西，缺一个就别验收：

| 要什么 | 长什么样 | 说明 |
| --- | --- | --- |
| 闸门结果 | `verify_code: suspects []`、`scan_hallucination: blocking false` | 两个都干净才算过 |
| 执行证据 | 命令 + 退出码 0 + 输出片段 | "测试都过了"四个字不算数 |
| 存证凭据 | `record_verification` 返回的记录 / `guard_cli receipt` | 重要任务必留，事后可复核 |

更省事的收法：直接让它跑 `guard_cli.py gate --root .`，四个阶段
（合规/符号/扫描/覆盖率）全绿再验收。

## 使用警告（每条都是真踩过的坑）

1. **它防"幻觉与谎报"，不防"逻辑错误"。** 能跑但跑错的代码不在它的
   射程内——业务对不对，仍然要你或 review 把关。
2. **别被"全部通过"说服。** 要退出码、要输出。没有日志的"测试都过了"
   只是口头声明。
3. **聊天里的闸门是软的，CI 里才是硬的。** 弱模型可能跳步——重申一次
   开场约束通常就能拉回来；真正绕不过的是合入前的
   `guard_cli.py gate`（退出码 1 = 不许合并）。
4. **第一次跑 gate 会"放行"存量问题**——基线机制只拦新增信号。
   这是设计（否则老项目第一天就红死），但意味着基线要定期复审
   （`baseline audit`）。
5. **`sandbox_run` 会真实执行命令。** AI 请求执行时你看一眼再批准；
   共享或 CI 环境务必配置 `sandbox_allowed_prefixes` 白名单。
6. **误报别硬扛。** `warning` 级命中只需在报告里交代；确定是合法用法
   就用 `guard_cli allow <词>` 沉淀掉——门禁只有越用越安静才活得下去。
7. **误报要报告。** 到仓库开 issue 附上被标记的行——作者把误报当 bug。

## 三个常见错误用法

- **只装不提**：装完插件从不说"过闸门再交"——工具在但闸门没人拉。
  至少把开场的六条约束贴上。
- **开场灌技术原理**：把设计文档发给 AI 当约束——噪音淹没重点。
  六条约束是按"AI 一次能记住"的长度调的。
- **拿它当测试框架**：它不写测试、不发现业务 bug，它只保证
  "AI 说的完成"有证据。

## 一分钟检查清单

- [ ] AgentSeed 已装且 MCP 已连接（新会话能看到 `agentseed_*` 工具）
- [ ] 开场贴了六条约束
- [ ] 过程中看到 AI 调用了 agentseed 工具
- [ ] 收尾拿到：闸门全绿 + 退出码证据 + 存证记录
- [ ] 重要任务有 receipt，合入前 CI 里 gate 是绿的
